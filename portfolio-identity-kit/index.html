6. Discernment & Rejection Note

Why Real Captures Over AI Stand-ins:

AI-generated software interfaces look synthetic and contain fake syntax upon inspection. Utilizing real high-resolution screenshots of active code execution, LangGraph workflows, and vector storage pipelines provides genuine proof of engineering execution.

Rejected Asset Analysis:

Asset: glowing_3d_neural_network_sphere.png (AI Generated)
Reason: The initial concept yielded glowing neon particle trails and hyper-detailed 3D nodes. While visually striking, it violated the core style note rule: the background must frame the work, not compete with it. It distracted from project descriptions and felt like a generic stock template. I rejected it in favor of a flat, minimal vector grid pattern.
